# Lineage: working agreement

Lineage is the family tree of AI math: an atlas where formulas morph into their descendants and every
formula is computed, not drawn. Audience: ML researchers and engineers (the bar is "a DeepMind engineer
would send this to a colleague") and curious practitioners on LinkedIn.

## Non-negotiables

1. **Correctness before beauty.** All math lives in `src/core` and must match `python/oracle.py`
   (independent references). Never edit `tests/fixtures/*` by hand; never loosen a tolerance to pass.
   After adding a computed formula, plant a bug and confirm a test fails.
2. **UI and scenes never compute.** They call `src/core`. Animation timing may be invented; numbers
   may not.
3. **Honest citations.** `status: "verified"` only after the locator was checked in the source itself.
   Edges are `historical` only when the child was actually derived from the parent.
4. **Consistent notation.** Follow CONTRIBUTING.md. Reuse token keys across a lineage so morphs carry
   meaning (`q` is the query from Luong to multi-head).
5. **No attribution lines.** Never add "generated by", co-author trailers, or tool credits to code,
   comments, docs, commit messages or PR descriptions in this repository.
6. **`npm run ci` passes before every commit.**

## Architecture

`src/core` math → `src/atlas` data and graph → `src/math` KaTeX, tokens, morph, symbol bus →
`src/ui` shell and probes, `src/scene` three.js. Tests in `tests/`, oracle in `python/`.

## Design direction (the WOW)

Current UI is the **lab**: functional, verified, deliberately plain. The production experience:

- **The sky (home).** A dark 3D constellation: every formula is a star, clustered by family, edges are
  faint filaments, the hub (softmax) burns brightest with filaments into every family. Idle camera
  drifts slowly. Search jumps anywhere.
- **Semantic zoom, one continuous camera move.** Star → formula card → the formula lifts off the card
  into its scene. Never a page load.
- **Evolution.** Moving to a child plays the morph (already built: `FormulaStage`) while the scene
  transforms with it, and the step's name appears ("divide by √d_k").
- **The formula is the controller.** Every symbol is bound to its scene object through `SymbolBus`
  in both directions. Dragging an object updates the value shown in the equation.
- **Lens.** For hub formulas, one switch re-skins the same math into each family's world.
- **Look:** near-black, one cyan accent (#5ee3d6), amber only for warnings and pass^k, hairlines,
  condensed display type (Barlow Condensed), JetBrains Mono for data, KaTeX for math. Bloom used
  sparingly. Must work at 390 px wide and honour `prefers-reduced-motion`.
- **Performance:** 60 fps on a laptop; lazy-load scenes; dispose everything on navigation.
