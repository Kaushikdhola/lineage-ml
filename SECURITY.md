# Security

The site is fully static: no server, no accounts, no cookies, no analytics that track individuals,
and nothing a visitor types is sent anywhere. Every number it shows is computed in the browser or
loaded from committed measurement files.

## Reporting a vulnerability

Please open a private security advisory on GitHub (Security → Report a vulnerability) rather than a
public issue. You will get a response within a few days.

## Reporting findings about other projects

Token X-ray measures third-party training libraries. Behaviour that looks like a bug in another project
is reported privately to its maintainers first, with a minimal reproduction, and described publicly as
a candidate finding until they confirm it.
